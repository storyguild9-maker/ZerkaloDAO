# Зеркало Дао

Локальная основа MVP для интерактивного отбора через семь даосских врат.

## Что уже есть

- Next.js app router, TypeScript, Tailwind.
- 7 конфигурируемых врат в `src/content/gates.ts`.
- 7 named UI-компонентов врат в `src/components/gates/GateStages.tsx`.
- Скрытая scoring-логика и архетипы в `src/lib/scoring`.
- Локальная SQLite-база через Prisma Client.
- Сохранение сессий, событий, попыток ворот, итогового профиля и контакта.
- Поведенческие события: клики, выборы, подсказки, ожидание, начало ввода, отправка текста, попытка ухода со страницы.
- Пользовательский результат без раскрытия точной формулы скоринга.
- Копирование результата и безопасный JSON-экспорт для пользователя.
- Админ-экран `/admin` для просмотра сессий, метрик, флагов риска, ответов и событий.
- Админ-действия: подтвердить/изменить доступ, отметить перспективного кандидата, оставить заметку, экспортировать полный JSON.
- Этическое предупреждение: это не диагноз, не медицинская, психологическая или юридическая оценка.

## Локальный запуск

```bash
npm install
npm run db:init
npm run dev
```

Открыть: `http://localhost:3000`.

Админка: `http://localhost:3000/admin?password=change-me`.

## Проверки

```bash
npm run db:init
npm test
npm run build
```

Дополнительно проверен полный HTTP-поток: создание сессии, прохождение 7 врат, результат, безопасный пользовательский экспорт, админ-ревью и полный админский экспорт.

## База данных

Основной `.env` для локальной разработки:

```env
DATABASE_URL="file:./dev.db"
ADMIN_PASSWORD="change-me"
```

На этой Windows-среде `prisma db push` может падать на schema engine без подробной ошибки, поэтому добавлен стабильный локальный обход:

```bash
npm run db:init
```

Он идемпотентно создаёт и обновляет нужные SQLite-таблицы, индексы и дополнительные колонки ревью через Prisma Client.

## Позже: GitHub и Supabase

Когда будем переносить основу на сайт:

- загрузим папку проекта в отдельный GitHub-репозиторий или подпапку общего репозитория;
- заменим SQLite `DATABASE_URL` на Supabase Postgres URL;
- переведём Prisma-схему на Postgres-миграции;
- при желании заменим JSON-строки в схеме на `Json`/`JsonB` поля;
- добавим нормальную авторизацию админки вместо простого локального пароля;
- вынесем секреты в переменные окружения хостинга.
